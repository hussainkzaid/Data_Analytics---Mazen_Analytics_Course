# IMDb Movie Industry Data Analytics Dashboard

An interactive, high-impact **Power BI Dashboard** that provides comprehensive analytical insights into global movie performance, studio economics, genre performance, and box office trends using IMDb dataset records.

---

## 📊 Executive Summary & Key Performance Indicators (KPIs)

- **Total Revenue:** $782 Billion
- **Total Production Budget:** $299 Billion
- **Net Profit:** $483 Billion
- **Gross Profit Margin:** 62%
- **Average Vote Rating:** 2.0
- **Popularity Score:** 12K

---

## 🛠️ Key Visualizations & Features

### 1. Financial Performance KPI Cards
High-level overview cards tracking overall commercial metrics including Revenue, Budget, Net Profit, and Profitability Margins across selected parameters.

### 2. Revenue Distribution by Genre (Radar Visual)
Detailed radar chart displaying earnings distribution across various movie genres including *Action, Comedy, Adventure, Drama, Animation, Horror, Science Fiction, Fantasy, Family, Thriller, Crime, Romance, Music, Mystery, War, Western, History, Documentary, and TV Movie*.

### 3. Studio Revenue vs. Budget Breakdown
Side-by-side horizontal stacked bar chart analyzing the top revenue-generating studios alongside their corresponding budgets:
- **Walt Disney Pictures:** $68bn Revenue | $26bn Budget
- **Paramount Pictures:** $35bn Revenue | $12bn Budget
- **Universal Pictures:** $35bn Revenue | $11bn Budget
- **Marvel Studios:** $30bn Revenue

### 4. Historical Box Office Revenue Trends (1960 – Present)
Interactive time-series line chart tracking the financial expansion of the film industry from 1960 through 2020+, highlighting key peak periods and historical market shifts.

### 5. Production Studio Decomposition Tree
Advanced root-cause drill-down visual mapping total revenue contributions across key studio networks (*Walt Disney, Paramount, Universal, Marvel Studios, Columbia Pictures, Warner Bros. Pictures, New Line Cinema, etc.*).

### 6. Interactive Filter & Navigation Panel
Sleek, dark-mode sidebar UI enabling multi-dimensional slicing:
- **Title Search / Selection**
- **Release Date Slicer**
- **Production Country Filter**
- **Global Reset All Filters Button**
- Dynamic UI page navigation (Overview, Deep Analytics, Drill-downs)

---

## 💻 Technology Stack & Tools Used

- **Business Intelligence & Visualization:** Microsoft Power BI Desktop
- **Data Modeling & Transformation:** Power Query (DAX calculations, custom KPI measures, revenue margin modeling)
- **Visual Extensions:** Radar Chart, Decomposition Tree Visual, Shape Maps, Stacked Bar Charts, Line Charts
- **UI/UX Design:** Dark Theme with Gold Accent Palette, Custom Navigation Panel

## 🚀 Getting Started

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/imdb-powerbi-dashboard.git
   ```
2. **Open in Power BI Desktop:**
   Launch Microsoft Power BI Desktop and open the project file (`.pbix`).
3. **Interact & Explore:**
   Use the left navigation pane to filter data by year, title, or production country to explore custom analytical views.
